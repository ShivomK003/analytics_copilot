# Analytics Copilot Frontend

The React dashboard lives in `src/`. Page composition belongs in `src/pages/`,
API clients in `src/api/`, query hooks in `src/hooks/` and reusable UI in
`src/components/`. Vitest suites live in `tests/`.

See the [repository README](../README.md#run-locally) for local setup and
validation commands and the [design system](../docs/DESIGN_SYSTEM.md) for
dashboard behavior and visual conventions.
